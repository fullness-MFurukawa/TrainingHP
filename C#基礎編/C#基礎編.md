# 研修名
C#基礎編

# キャッチコピー
C#の第一歩が、エンジニアの可能性を広げる。基本構文からオブジェクト指向まで、確実に身につける。

# 研修概要
## ■ 本研修について
本研修では、C#の基本構文からオブジェクト指向プログラミング・クラスライブラリまでを体系的に学びます。ドリルと演習問題に取り組みながら、実務で必要なC#の基礎スキルを確実に習得します。
## ■ 本研修の3つの特徴
✍️ ドリルと演習で「書ける」を実現する
各章にドリルと演習問題を用意。模範解答付きで自己確認しながら学習できます。手を動かすことで、知識を実践力へ確実に変換します。
📐 基本構文からOOPまで段階的に積み上げる
変数・条件分岐・ループなどの基本構文から、クラス・継承・ポリモーフィズムまで15段階の演習で段階的に習得します。
🔧 クラスライブラリで実務直結スキルを習得
List・Dictionary・DateTime・ファイルI/O・Newtonsoft.Jsonなど、実務プロジェクトで頻繁に使うクラスライブラリを実践的に習得します。
## ■ 到達目標（受講後に身につくスキル）
・C#の基本構文（変数・条件分岐・ループ・関数・配列）を理解し、プログラムを実装できる
・クラス・継承・インターフェイス・ポリモーフィズムなどOOPの概念を理解し、実装できる
・List・Dictionary・DateTime・ファイルI/Oなどの標準クラスライブラリを実務で活用できる

# こんな企業にお勧め
- 新卒・未経験エンジニアにC#の基礎を体系的に習得させたい
- 他言語エンジニアをC#開発チームにアサインするにあたりスキル転換を図りたい
- C#エンジニアの基礎スキルにばらつきがあり、チーム全体の底上げを図りたい
- .NET・C#を主要技術スタックとして採用しており、新規メンバーの早期戦力化を図りたい
- C#テストコード基礎・C# BDDへのステップアップを見据えた基礎固めをさせたい

## 日数
3日間

# カリキュラム詳細（全3日間）

| 日程 | 章・学習テーマ | 学習内容・習得スキル |
|------|--------------|-------------------|
| 1日目 | 第1章：.NETとC#の概要 | .NETの概要・C#プログラムの作成と実行・演習環境のセットアップを理解する。 |
| 　 | 第2章：基本構文 | プログラムの基本事項・変数と定数・コンソール入出力・演算子・配列・条件分岐（if・switch）・繰り返し（for・while・foreach）・関数を習得する。ドリルと演習で実践力を定着させる。 |
| 2日目 | 第3章前半：オブジェクト指向（クラス〜継承） | クラス・インスタンス・コンストラクタ・オーバーロード・カプセル化（プロパティ・アクセス修飾子）・継承を段階的な演習を通じて習得する。 |
| 　 | 第3章後半：オブジェクト指向（インターフェイス〜例外処理） | 抽象クラスとインターフェイス・ポリモーフィズム・静的メンバ・拡張メソッド・例外処理（try・catch・finally・独自例外）を習得する。 |
| 3日目 | 第3章：OOP演習・定着 | 前日までに学んだOOPの概念を演習問題（クラス〜ポリモーフィズム〜例外処理）を通じて定着させる。模範解答で自己確認する。 |
| 　 | 第4章：クラスライブラリ | クラスライブラリの概要・基本的なクラス（DateTime・Math・String）・コレクション（List・Dictionary）・ファイルI/O・Newtonsoft.Jsonライブラリを実践的に習得する。 |

> ※ 各章にドリルと演習問題・模範解答が付属しています。オプション章は受講者のレベルに応じて追加可能です。
