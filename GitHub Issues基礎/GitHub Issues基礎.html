GitHub Issues基礎

開発サイクルを繋ぎ、チームの思考を同期する

タスク管理ツールではなく、開発の司令塔として使う。

研修概要

🔑 GitHub IssuesをSSOT（唯一の真実）として活用する
Issues・Repository・Actionsが連動する循環サイクルの「起点」として機能させることで、チームの思考を同期させ、透明性の高い自律的な開発サイクルを構築します。

■ 本研修について

本研修は、GitHub IssuesをSSOT（唯一の真実）として活用し、開発サイクルの「司令塔」として機能させる方法を体系的に学ぶプログラムです。

GitHub Issues・Repository・Actionsが連動する循環サイクルを理解した上で、ラベル・担当者・マイルストーンによるIssue管理・YAMLテンプレートによる報告の標準化・GitHub Actionsとのイベントドリブンな連携を実践します。

「なぜそのコードが必要なのか」というWhyをIssueに記録し、チームの思考を同期させることで、透明性が高く自律的な開発サイクルを構築する力を身につけます。

■ 本研修の3つの目的

本研修では、以下の3つを習得することを目的としています。

1. GitHub IssuesをSSOTとして活用できるようになる

Issues・Repository・Actionsが連動する循環サイクルを理解し、なぜIssueが開発の起点（Why）になるのかを説明できるようになる。

2. ラベル・テンプレートによるIssue管理を標準化できるようになる

ラベル・担当者・マイルストーンの3つの属性を使いこなし、YAML形式のIssueテンプレートを定義・配置して、報告の質を均一化できるようになる。

3. GitHub Actionsとのイベントドリブンな連携を構築できるようになる

Issueイベントをトリガーにしたワークフローを実装し、自動応答・動的制御による開発サイクルの自動化を実現できるようになる。

到達目標（受講後に身につくスキル）

🔄GitHubエコシステムの理解

  • Issues・Repository・Actionsの循環サイクルを説明できる
  • なぜIssueが開発の起点（Why）になるのかをエンジニア・マネージャー・組織それぞれの視点で説明できる

📋Issue管理・標準化

  • ラベル・担当者・マイルストーンでIssueのライフサイクルを管理できる
  • YAML形式のIssueテンプレートを定義・配置し、チームの報告品質を均一化できる
  • 自由記述による非構造化の弊害を防ぎ、ナレッジを資産化できる

⚙️GitHub Actions連携・自動化

  • IssueイベントをトリガーにGitHub Actionsワークフローを起動できる
  • 自動応答・動的制御による開発サイクルの自動化を実装できる
  • IssueのステータスをActionsで自動更新し、開発サイクルの停滞を防ぐ仕組みを構築できる

受講にあたっての前提知識

GitHubの基礎知識

  • GitHubアカウントを持ち、リポジトリの基本操作（作成・クローン・プッシュ）ができること。
  • GitHubのIssue・Pull Requestの概念をなんとなく知っていること。

基本的なPC・OS操作

  • Visual Studio Codeを使ったファイルの作成・編集ができること。
  • WSL2（Ubuntu）環境での初歩的なコマンド入力に抵抗がないこと。
