# 研修概要
## ■ 本研修について
本研修は、GitHub IssuesをSSOT（唯一の真実）として活用し、チーム開発の標準化と自動化を実現する方法を学ぶプログラムです。
Issueの運用手続き・YAMLテンプレートによる標準化・GitHub Actionsとのイベントドリブンな連携を体系的に習得し、開発サイクルの「司令塔」として機能するGitHub Issuesの真の価値を体得します。

## ■ 本研修の3つの特徴
本研修では、以下の3つを習得することを目的としています。
1. GitHub IssuesをSSOTとして活用できるようになる
Issues・Repository・Actionsが連動する循環サイクルを理解し、なぜIssueが開発の起点（Why）になるのかを説明できるようになる。
2. ラベル・テンプレートによるIssue管理を標準化できるようになる
ラベル・担当者・マイルストーンの3つの属性を使いこなし、YAML形式のIssueテンプレートを定義・配置して、報告の質を均一化できるようになる。
3. GitHub Actionsとのイベントドリブンな連携を構築できるようになる
Issueイベントをトリガーにしたワークフローを実装し、自動応答・動的制御による開発サイクルの自動化を実現できるようになる。

## ■ 到達目標（受講後に身につくスキル）
本研修を修了すると、以下のスキルが身につきます。
### GitHubエコシステムの理解
Issues・Repository・Actionsが連動する循環サイクルを説明できる
なぜIssueが開発の起点（Why）になるのかを、エンジニア・マネージャー・組織それぞれの視点で説明できる
### Issue管理・標準化
ラベル・担当者・マイルストーンの3つの属性を使いこなし、IssueをオープンからクローズまでのライフサイクルとWFで管理できる
YAML形式のIssueテンプレートを定義・配置し、チームの報告品質を均一化できる
自由記述による非構造化データの弊害を防ぎ、ナレッジを資産化できる
### GitHub Actions連携・自動化
IssueイベントをトリガーにGitHub Actionsワークフローを起動できる
自動応答・動的制御による開発サイクルの自動化を実装できる
IssueのステータスをActionsで自動更新し、開発サイクルの停滞を防ぐ仕組みを構築できる

# こんな企業にお勧め
