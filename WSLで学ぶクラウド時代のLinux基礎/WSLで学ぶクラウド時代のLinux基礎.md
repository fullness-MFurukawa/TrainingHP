# 研修名
WSLで学ぶクラウド時代のLinux基礎

# キャッチコピー
AWS・Azureへの移行を、WSLから始める。クラウド時代のLinux基礎を体系的に習得する。

# 研修概要
## ■ 本研修について
クラウドの現場はLinuxで動いています。本研修では、WindowsユーザーがWSL2を使ってLinuxの基本構造から実務コマンドまでを体系的に学び、AWS・Azureのクラウドサーバー操作に移行できる基礎力を習得します。
## ■ 本研修の3つの特徴
🪟 Windowsユーザーが安心して始められる
Windowsとのディレクトリ対応関係・WSLからWindowsファイルへのアクセス方法など、Windows環境からの移行を丁寧にサポートします。Linuxが初めてでも安心して学習できます。
🐧 カーネル・シェルから実務コマンドまで体系的に学ぶ
Linuxの基本構造（カーネル・シェル）から、ファイル操作・プロセス管理・パッケージ管理・SSH転送まで全12章で体系的に習得します。
☁️ AWS・Azureへの移行を見据えた実務直結の内容
クラウド環境でのLinuxサーバー操作に直結するコマンドと知識を習得します。研修後すぐにクラウド移行プロジェクトに活かせる内容です。
## ■ 到達目標（受講後に身につくスキル）
・WSL2（Ubuntu）環境でLinuxコマンドを自走して実行できる
・ファイル検索（find・grep）・圧縮解凍（tar・zip）
・SSH転送（scp）を実務で活用できる・AWS・Azureのクラウドサーバー操作に必要なLinux基礎力を身につけている

# こんな企業にお勧め
- WindowsエンジニアにLinuxの基礎を習得させてクラウド移行に備えたい
- AWS・Azure導入に向けてエンジニアのLinuxスキルを底上げしたい
- LinuxコマンドがわからずクラウドサーバーやDockerの操作に苦労しているエンジニアがいる
- DX推進に伴いオンプレミスからクラウドへの移行を計画している
- 新卒・若手エンジニアにLinuxの基礎を体系的に習得させたい
- Windowsしか触ったことのないエンジニアにLinux環境を安心して体験させたい
