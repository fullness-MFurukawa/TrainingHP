## 6. カリキュラム詳細

**指示：** 2日間のカリキュラム詳細をマークダウンの表で作成してください。

**選定：** 以下の構成で確定

| 日程 | 章・学習テーマ | 学習内容・習得スキル |
|------|--------------|-------------------|
| 1日目 | 第1章：Go言語の概要 | Go言語の歴史・主な特徴・バージョン履歴（1.0〜1.24）を理解する。シンプル・高速・並行処理という3つの強みと、クラウドネイティブ開発における位置づけを把握する。 |
| 　 | 第2章：基本構文 | 標準出力・コメント・演算子・変数と定数・列挙型・制御文を習得する。Goのシンプルな文法スタイルを実装しながら体得する。 |
| 　 | 第3章：データ型 | 文字と文字列・配列・スライス・マップ・構造体・ポインタ・ゼロ値・イテレータ（Go1.23〜）を習得する。 |
| 　 | 第4章：関数 | 関数の宣言・多値返却・可変長関数・匿名関数・関数型・遅延実行・ジェネリクス（型パラメータ）を習得する。 |
| 　 | 第5章：メソッド | レシーバ・値の変更・ジェネリクスを用いたメソッド設計を習得する。 |
| 　 | 第6章：インターフェイス | インターフェイスの特徴・空インターフェイス・埋め込み・型アサーション・型switch・ジェネリクスを習得する。 |
| 2日目 | 第7章：エラー | errorインターフェイス・パニック・リカバリ・ランタイムパニック・エラー処理機能の使い分けを習得する。 |
| 　 | 第8章：並行処理 | ゴルーチン・終了の同期化・チャネル・チャネルを使った送受信・select文による通信制御を習得する。 |
| 　 | 第9章：パッケージ・モジュール | Goのパッケージ・import文・Goモジュール・go.modファイル・外部モジュール・モジュールの最適化を習得する。 |
| 　 | 第10章：ビルド | go buildコマンド・クロスコンパイル・go:embedを習得する。 |
| 　 | 第11章：テスト | Goのテストスタイル・testingパッケージ・testifyフレームワークを習得する。 |
| 　 | 第12章：標準パッケージ | 日時操作・ファイル・ディレクトリ操作・JSON操作・ロギングを習得する。サンプルコードと演習課題で実践力を定着させる。 |
