Git/GitHub ソースコード管理入門

バージョン管理の基礎からチーム開発まで

Git/GitHubで学ぶ、ソースコード管理の基本と実践。

研修概要

■ 本研修について

本研修は、Git/GitHubを用いたソースコード管理の基本から、チーム開発を安全に進めるための実践まで体系的に学ぶハンズオンプログラムです。

バージョン管理の概念・Gitの基本操作（add・commit・push・pull）・GitHubでのソースコード共有を習得した上で、ブランチ・マージ・コンフリクト解消といったチーム開発に必須のスキルを演習を通じて体得します。

言語・フレームワークを問わず、すべてのエンジニアに必要な基礎教養であるGit/GitHubを、本研修でしっかりと身につけることを目指します。

■ 本研修の3つの目的

本研修では、以下の3つを習得することを目的としています。

1. Gitの基本操作とバージョン管理の体得

バージョン管理の概念・ローカルリポジトリの操作（add・commit・status）・コミット間の移動を実装レベルで習得し、変更履歴を正しく管理できる力を身につける。

2. GitHubを使ったソースコード共有の習得

GitHubリポジトリの作成・ローカルとGitHubの同期（push・pull）・.gitignoreを使ったGit管理対象からの除外設定を習得し、チームでソースコードを安全に共有できるようになる。

3. チーム開発を安全に進めるスキルの習得

ブランチの作成・マージ・コンフリクトの解消を演習を通じて体得し、複数の開発者が同じリポジトリで安全に開発を進められるようになる。

到達目標（受講後に身につくスキル）

🗂️Gitの基本操作

  • バージョン管理の概念（集中型・分散型の違い）を説明できる
  • ローカルリポジトリの作成・add・commit・statusを自走して操作できる
  • コミット履歴を確認し、特定のコミットに移動できる

☁️GitHubでのソースコード共有

  • GitHubリポジトリを作成し、ローカルとGitHubを同期（push・pull）できる
  • .gitignoreを使ってGit管理対象から除外するファイルを設定できる
  • チームメンバーをリポジトリに招待し、クローンして共同開発を始められる

👥チーム開発・ブランチ管理

  • ブランチを作成・切り替え・削除し、並行開発を安全に進められる
  • ブランチをマージし、コンフリクトを自力で解消できる
  • Git Graph・GitLensを使ってコミット履歴・ブランチをビジュアルで確認できる

カリキュラム詳細（全2日間）

日程 章・学習テーマ 学習内容・習得スキル
1日目 第1章：ソースコード管理の概要 ソースコード管理・バージョン管理の必要性と概要を学ぶ。集中型（SVN等）と分散型（Git）の違い・それぞれのメリット・デメリットを理解する。
第2章：GitとGitHubの概要 Gitの概要・主な機能・ローカルリポジトリとリモートリポジトリの違いを理解する。GitHubをはじめとするリモートリポジトリサービスの種類・Gitクライアントツール（Git Graph・GitLens）の役割を把握する。
第3章：Gitの基本操作 Gitの環境準備（初期設定・VSCode連携）を行い、ローカルリポジトリの作成・ステージング（add）・コミット・git statusによる状態確認・コミット間の移動を実践する。
第4章：GitHubによるソースコード共有 GitHubリポジトリの作成・ローカルリポジトリとGitHubの紐づけ・push/pullによる同期・.gitignoreを使ったGit管理対象からの除外設定を実践する。
2日目 第5章：チーム開発とGitHub リポジトリへのメンバー招待・クローンによるリポジトリの取得・pullによる最新コードの取り込みを実践する。複数人での開発フローを体験し、チーム開発の基本を習得する。
第6章：チーム開発を安全に進める ブランチの作成・切り替え・削除・マージを実践し、並行開発の流れを体得する。マージ時に発生するコンフリクトの原因・解消方法を演習を通じて習得し、チーム開発を安全に進める力を身につける。

※ 各章末に演習を実施します。

※ Git Graph・GitLensを活用したビジュアルなコミット管理も体験します。

※ 2日目は第6章（ブランチ・マージ・コンフリクト）の演習時間を十分に確保します。

受講にあたっての前提知識

基本的なPC・OS操作

  • Windows 11の基本操作（ファイル管理・フォルダ操作）ができること。
  • Visual Studio Codeを使ったファイルの作成・編集・保存ができること。
  • コマンドプロンプト・PowerShellでの基本的なコマンド入力に抵抗がないこと。

プログラミングの基礎知識

  • 任意のプログラミング言語でのソースコード作成・実行経験があること。

あると望ましい知識 推奨

  • GitやGitHubの名前・概念をなんとなく知っていること（操作経験は不要）。
  • テキストファイルの編集・差分確認の経験。
