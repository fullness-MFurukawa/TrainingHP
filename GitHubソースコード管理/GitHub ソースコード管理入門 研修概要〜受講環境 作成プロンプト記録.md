### 確定文（本研修について・案A）

本研修は、Git/GitHubを用いたソースコード管理の基本から、チーム開発を安全に進めるための実践まで体系的に学ぶハンズオンプログラムです。

バージョン管理の概念・Gitの基本操作（add・commit・push・pull）・GitHubでのソースコード共有を習得した上で、ブランチ・マージ・コンフリクト解消といったチーム開発に必須のスキルを演習を通じて体得します。

言語・フレームワークを問わず、すべてのエンジニアに必要な基礎教養であるGit/GitHubを、本研修でしっかりと身につけることを目指します。

### 確定文（本研修の目的・案A）

本研修では、以下の3つを習得することを目的としています。

**1. Gitの基本操作とバージョン管理の体得**
バージョン管理の概念・ローカルリポジトリの操作（add・commit・status）・コミット間の移動を実装レベルで習得し、変更履歴を正しく管理できる力を身につける。

**2. GitHubを使ったソースコード共有の習得**
GitHubリポジトリの作成・ローカルとGitHubの同期（push・pull）・.gitignoreを使ったGit管理対象からの除外設定を習得し、チームでソースコードを安全に共有できるようになる。

**3. チーム開発を安全に進めるスキルの習得**
ブランチの作成・マージ・コンフリクトの解消を演習を通じて体得し、複数の開発者が同じリポジトリで安全に開発を進められるようになる。

## ポイント・コツ

| ポイント | 内容 |
|----------|------|
| 概要と目的をまとめて選択できる | 「概要と目的は案Aにします」の一言で両セクションを同時に確定できる |
| 全セクション確定後にプロンプト記録を作成する | 途中でプロンプト記録を作成するより、全セクション確定後にまとめて作成する方が効率的 |
| 言語を問わない前提知識の書き方 | Git/GitHubは言語を問わないため「任意のプログラミング言語」と明記すると幅広い受講者に対応できる |
| GitHubアカウントの注記を追加する | 無料プランで受講できることを明示すると受講者の不安が解消される |
| シリーズで最もシンプルな環境構成 | DB・SDK不要のため環境構築の手間が少なく、入門コースとして受講しやすい |

## 全体の流れまとめ

```
STEP 1｜「研修概要をお願いします」と指示する
STEP 2｜「概要と目的は案〇〇にします」と両セクションをまとめて選択する
STEP 3｜「到達目標に進みましょう」と指示して案を選択する
STEP 4｜「お願いします」でこんな企業にお勧めの案を選択する
STEP 5｜「カリキュラム詳細に進みます。日数は〇日間にします」と指示して案を選択する
STEP 6｜「受講にあたっての前提知識に進みます」と指示して案を選択する
STEP 7｜「お願いします」で受講環境の案を選択してMarkdownに保存する
STEP 8｜全セクション確定後にプロンプト記録の作成を依頼する
```
