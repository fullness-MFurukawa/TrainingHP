# タイトル

# キャッチコピー
- Git/GitHubで学ぶ、ソースコード管理の基本と実践。
バージョン管理の概念からGitの基本操作・GitHubでの共有・チーム開発・ブランチ管理まで。すべての開発者に必要な基礎を、演習を通じて体得する研修。

# 研修概要
## ■ 本研修について
本研修は、Git/GitHubを用いたソースコード管理の基本から、チーム開発を安全に進めるための実践まで体系的に学ぶハンズオンプログラムです。
バージョン管理の概念・Gitの基本操作（add・commit・push・pull）・GitHubでのソースコード共有を習得した上で、ブランチ・マージ・コンフリクト解消といったチーム開発に必須のスキルを演習を通じて体得します。
言語・フレームワークを問わず、すべてのエンジニアに必要な基礎教養であるGit/GitHubを、本研修でしっかりと身につけることを目指します。
## ■ 本研修の3つの目的
本研修では、以下の3つを習得することを目的としています。
1. Gitの基本操作とバージョン管理の体得
バージョン管理の概念・ローカルリポジトリの操作（add・commit・status）・コミット間の移動を実装レベルで習得し、変更履歴を正しく管理できる力を身につける。
2. GitHubを使ったソースコード共有の習得
GitHubリポジトリの作成・ローカルとGitHubの同期（push・pull）・Git管理対象からの除外（.gitignore）を習得し、チームでソースコードを安全に共有できるようになる。
3. チーム開発を安全に進めるスキルの習得
ブランチの作成・マージ・コンフリクトの解消を演習を通じて体得し、複数の開発者が同じリポジトリで安全に開発を進められるようになる。
## ■ 到達目標(受講後に身につくスキル)
本研修を修了すると、以下のスキルが身につきます。
### Gitの基本操作
バージョン管理の概念（集中型・分散型の違い）を説明できる
ローカルリポジトリの作成・add・commit・statusを自走して操作できる
コミット履歴を確認し、特定のコミットに移動できる
### GitHubでのソースコード共有
GitHubリポジトリを作成し、ローカルとGitHubを同期（push・pull）できる
.gitignoreを使ってGit管理対象から除外するファイルを設定できる
チームメンバーをリポジトリに招待し、クローンして共同開発を始められる
### チーム開発・ブランチ管理
ブランチを作成・切り替え・削除し、並行開発を安全に進められる
ブランチをマージし、コンフリクトを自力で解消できる
Git Graph・GitLensを使ってコミット履歴・ブランチをビジュアルで確認できる

# こんな企業にお勧め
本研修は、次のような企業・チームに特にお勧めします。
- 開発チーム全体のソースコード管理を標準化し、チーム開発の品質を底上げしたい
- GitHub ActionsによるCI/CD導入を見据えて、Git/GitHubの基礎をチームに定着させたい
- 言語・技術を問わず、すべてのエンジニアに必要な開発基礎力を強化したい

# 前提知識・スキル-> 受講にあたっての前提知識
## 基本的なPC・OS操作
Windows 11の基本操作（ファイル管理・フォルダ操作）ができること。
Visual Studio Codeを使ったファイルの作成・編集・保存ができること。
コマンドプロンプト・PowerShellでの基本的なコマンド入力に抵抗がないこと。
## プログラミングの基礎知識
任意のプログラミング言語でのソースコード作成・実行経験があること。
## あると望ましい知識 推奨
GitやGitHubの名前・概念をなんとなく知っていること（操作経験は不要）。
テキストファイルの編集・差分確認の経験。

# 必要な受講環境

| 区分 | 環境 / ツール | 役割・用途 |
|------|--------------|-----------|
| ホストOS | Windows 11 | 研修用PCの基本環境 |
| IDE | Visual Studio Code | コード編集・Gitの操作・ターミナル操作 |
