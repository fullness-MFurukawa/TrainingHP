## 品質 — 優れている点

**一気通貫の構成**
VNetのネットワーク設計からVM・Azure DB・Blob Storage構築、アプリケーション公開、監視（Azure Monitor）、リソース削除まで、Azureインフラの全工程を一貫して体験できる。AWSハンズオンと同じ設計思想で構成されており、両クラウドを比較しながら学べる。

**Azure固有機能の充実**
Azure DNS・Azure Key Vault（証明書管理）・Microsoft Entra ID・Network Security Group（NSG）・システムルートなど、AWSとは異なるAzure固有の概念・サービスが丁寧に解説されている。

**Key Vault・DNS連携**
Azure Key Vault（証明書）とAzure DNSを組み合わせたHTTPS公開の仕組みをダイアグラムで明示。「ドメイン所有確認→証明書発行→DNS名前解決→HTTPS接続」という実務の流れを一気に体験できる。

**Microsoft Entra ID**
旧Azure ADから刷新されたMicrosoft Entra IDとAzure RBACを取り扱う。エンタープライズ環境での認証・認可の最新標準を学べる点が他研修と大きく差別化される。

**Java・C#両対応**
AWSハンズオンと同様に、Spring Boot（Java）とASP.NET Core（C#）の両方で対応。同一インフラ上で2言語を選択して学べる構成は市場でも極めて希少。

**習得できる主な技術・概念**

`VNet` `サブネット` `システムルート` `Virtual Machine（VM）`
`Network Security Group（NSG）` `Public IP` `SSH公開鍵` `NIC`

## 🏆 AWSハンズオンとの比較・差別化

### AWS vs Azure サービス対応表

| AWSサービス | Azureサービス | 役割 |
|------------|--------------|------|
| VPC | VNet（Virtual Network） | 仮想ネットワーク |
| EC2 | Virtual Machine（VM） | 仮想サーバー |
| Security Group | Network Security Group（NSG） | ネットワークセキュリティ |
| Elastic IP | Public IP | パブリックIPアドレス |
| RDS（PostgreSQL） | Azure Database for PostgreSQL | マネージドDB |
| S3 | Azure Blob Storage | オブジェクトストレージ |
| Route 53 | Azure DNS | DNSサービス |
| ACM | Azure Key Vault（証明書） | 証明書管理 |
| IAM | Microsoft Entra ID + Azure RBAC | 認証・認可 |
| CloudWatch | Azure Monitor | 監視・ログ・アラート |

### Azure固有の差別化ポイント

**1. Key Vault（証明書管理）**
AWSのACMが証明書の自動管理に特化しているのに対し、Azure Key Vaultは証明書・シークレット・暗号鍵を統合管理する。セキュリティ管理の柔軟性が高い。

**2. Microsoft Entra ID（旧Azure AD）**
Microsoft 365・Teams・Windows Serverと統合されたID管理基盤。エンタープライズ環境では最も普及している認証基盤で、Office 365ユーザーをそのままAzureリソースに接続できる。

**3. NSG（Network Security Group）**
サブネット・NICの両レベルでセキュリティルールを設定できる。AWSのセキュリティグループより粒度が細かく、エンタープライズ向けのネットワーク設計に強い。

**4. システムルート**
AzureはVNet内のサブネット間通信がシステムルートにより自動で有効化される。AWS（VPC）との挙動の違いを理解することで、マルチクラウド対応力が身につく。

## 総評

本コースはAWSハンズオンと設計思想を共有しながら、**Azure固有の概念（Key Vault・Microsoft Entra ID・NSG・システムルート）を丁寧に扱う最高水準の研修**です。

Microsoft 365・Teams・Entra IDを利用するエンタープライズ企業へのAzure導入支援として、市場でも最も需要の高いスキルセットを網羅しています。

AWSハンズオンとセットで提案することで、**「AWS・Azure双方に対応できるクラウドエンジニアの育成」**という強力な提案が可能になります。

- Microsoft 365・Teams・Entra ID環境を持つ企業のC#・Javaエンジニア
- AWSハンズオン受講後にAzureも習得したいマルチクラウド対応エンジニア
- C#シリーズで学んだアプリケーションをAzure上で動かす体験をしたいエンジニア
- Azure環境でのWebアプリケーション構築・公開・運用の実務スキルを習得したいエンジニア
