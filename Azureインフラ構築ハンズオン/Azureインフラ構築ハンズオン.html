ネットワーク設計からアプリケーション公開まで

使い慣れた言語で、Azureインフラの実務を体験する。

研修概要

🔧 Java（Spring Boot）またはC#（ASP.NET Core）から選択して受講できます
アプリケーション開発フェーズは使い慣れた言語を選択できるため、JavaエンジニアもC#エンジニアも同じAWSインフラ研修を受講できます。

■ 本研修について

本研修は、Azure上にWebアプリケーションを構築・公開・運用する一連の流れを通じて、クラウド環境における実務で必要となる基礎知識と考え方を身につけるハンズオンプログラムです。

VNet（ネットワーク設計）・VM（サーバー構築）・Azure Database for PostgreSQL（データベース）・Azure Blob Storage（ストレージ）を段階的に構築し、Nginx・HTTPSを含む本番を意識したインフラ環境を自分の手で作り上げます。Microsoft Entra ID・Azure Monitorについては講義形式で概念と役割を体系的に理解します。

アプリケーション開発フェーズはJava（Spring Boot）またはC#（ASP.NET Core）から選択できるため、使い慣れた言語でAWSインフラとの連携を実践できます。「作って終わり」ではなく、リソース削除まで含めたクラウド運用の全工程を体験します。

■ 本研修の4つの目的

本研修では、以下の4つを習得することを目的としています。

1. インフラ構築・理解

VPC上にWebアプリケーション用の基本的なネットワーク構成を設計・構築できる。EC2・RDS・S3を組み合わせた典型的なWebアプリケーション基盤を理解できる。Azure DNS・Azure Key Vaultを用いたHTTPSによる公開の仕組みを説明できる。

2. アプリケーションとインフラの関係理解

Java（Spring Boot）またはC#（ASP.NET Core）のWebアプリケーションがどのAWSサービスと、どのように連携しているかを説明できる。アプリケーション視点とインフラ視点の役割分担を理解できる。

3. セキュリティ・運用の概念理解 Microsoft Entra ID・Azure Monitorは講義

Microsoft Entra IDによる認証・認可の基本を理解できる。Azure Monitorによる監視・ログ・アラームの役割を説明できる。

4. クラウド運用の基礎

作成したAWSリソースを依存関係を意識して安全に削除できる。
