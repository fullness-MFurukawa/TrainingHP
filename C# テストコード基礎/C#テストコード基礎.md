# 研修名
C#テストコード基礎
- MSTestで学ぶユニットテストと結合テスト -

# キャッチコピー
テストを書く習慣が、コードの品質を変える。C#で学ぶ、実務テストコードの基礎。

# 研修概要
## ■ 本研修について
本研修では、C#によるテストコードの基礎を体系的に学びます。MSTestを用いたユニットテストの作成から、テスト用属性・例外処理のテスト・カバレッジ計測・Moqを用いた結合テストまで、実務で必要なテストコードのスキルを習得します。
## ■ 本研修の3つの特徴
📋 テストケース設計の思考プロセスまで学ぶ
境界値・同値分割・代表値を意識したテストケース表（観点・入力・期待結果・理由）の作成方法を習得します。「なぜそのテストケースを選ぶか」まで理解できます。
⚙️ MSTestの実務属性を完全習得
DataRow・DataTestMethod・TestInitialize・TestCleanup・TestCategoryなど、実務でよく使うMSTestの属性を網羅的に習得します。
🔗 Moqによる結合テストとカバレッジ計測まで一貫して学ぶ
インターフェイスのモック生成・Verify検証によるMoqの結合テストと、カバレッジ計測レポートの取得・可視化まで習得します。
## ■ 到達目標（受講後に身につくスキル）
・境界値・同値分割・代表値を意識したテストケースを設計・作成できる
・MSTestを用いてユニットテスト・例外処理テストを実装できる
・Moqを用いたインターフェイスのモックと結合テストを実装できる

# こんな企業にお勧め
- C#エンジニアのテストコードスキルにばらつきがあり、チーム全体に標準化したい
- テストを書く習慣がなく、品質管理をテスト自動化で改善したい
- 新卒・若手C#エンジニアにテストコードの基礎を体系的に習得させたい
- 「コードは書けるがテストが書けない」エンジニアのスキルアップを図りたい
- テストケース設計の考え方をエンジニア全員に身につけさせたい

# カリキュラム詳細（全1日間）

| 日程 | 章・学習テーマ | 学習内容・習得スキル |
|------|--------------|-------------------|
| 1日目 | 第1章：MSTestの概要 | MSTestの概要・テストの種類（ユニット・統合・E2E）・MSTestプロジェクトの構成を理解する。 |
| 　 | 第2章：ユニットテスト（単体テスト） | テストの目的・手順・テストターゲットの実装・テストケース設計（境界値・同値分割・代表値）・テストドライバの作成・Assertメソッド・テストの実行と結果確認を習得する。 |

| 　 | 第4章：例外処理のテスト | ExpectedException属性・Assert.ThrowsException・例外メッセージの検証を習得し、異常系テストを実装する。 |
