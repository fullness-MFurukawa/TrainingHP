## 6. カリキュラム詳細

**指示：** 1日間のカリキュラム詳細をマークダウンの表で作成してください。

**選定：** 以下の構成で確定

| 日程 | 章・学習テーマ | 学習内容・習得スキル |
|------|--------------|-------------------|
| 1日目 | 第1章：MSTestの概要 | MSTestの概要・テストの種類（ユニット・統合・E2E）・MSTestプロジェクトの構成を理解する。 |
| 　 | 第2章：ユニットテスト（単体テスト） | テストの目的・手順・テストターゲットの実装・テストケース設計（境界値・同値分割・代表値）・テストドライバの作成・Assertメソッド・テストの実行と結果確認を習得する。 |
| 　 | 第3章：実務でよく使うテスト用属性 | DataRow・DataTestMethod・TestInitialize・TestCleanup・ClassInitialize・Ignore・TestCategoryなどの実務属性を習得し、効率的なテスト実装を実践する。 |
| 　 | 第4章：例外処理のテスト | ExpectedException属性・Assert.ThrowsException・例外メッセージの検証を習得し、異常系テストを実装する。 |
| 　 | 第5章：カバレッジ | カバレッジの概念・テスト結果の可視化・カバレッジ計測レポートの取得と読み方を習得する。 |
| 　 | 第6章：結合テスト | モックの概念・Moqによるインターフェイスのモック生成・依存性注入・Verify検証を習得し、結合テストを実装する。 |

> ※ 各章に演習課題・模範解答・実行結果スクリーンショットが付属しています。
