# 研修概要
## ■ 本研修について
本研修では、C#を用いたビヘイビア駆動型開発（BDD）の基本から実践までを学びます。Gherkinによるシナリオ記述を起点に、ハンズオン形式で全レイヤーのテスト実装を習得します。
## ■ 本研修の特徴
### 📝自然言語で書く
GherkinシナリオGiven・When・Thenの形式で誰もが読めるシナリオを記述。仕様とテストを一致させる開発スタイルを体験します。
### ⚙️Reqnrollで自動テストに変換
GherkinシナリオをReqnrollが自動テストに変換。.NET8対応の最新フレームワークで、シナリオ駆動の開発を実践します。
### 🏗 4層アーキテクチャを一気通貫でテスト
ドメイン層からE2Eまで、Gherkin×Reqnrollを軸にした一貫したテスト戦略を習得します。

## ■ 到達目標（受講後に身につくスキル）
・Gherkinでシナリオを記述し、Reqnrollで自動テストとして実行できる
・ドメイン層からE2Eまで一貫したBDDテストを実装できる
・DDD×BDDを組み合わせた設計・実装ができる

# カリキュラム詳細（全2日間）

| 日程 | 章・学習テーマ | 学習内容・習得スキル |
|------|--------------|-------------------|
| 1日目 | 第1章：BDDとハンズオンの概要 | BDDの歴史・基本原則・TDDとの違いを理解する。Gherkin・Reqnroll・Playwright・Moqの概要と役割を把握し、ハンズオンのアーキテクチャとテストの基本的な流れを理解する。 |
| 　 | 第2章：Gherkin | Feature・Scenario・Scenario Outline・Background・Ruleなどのセクションキーワード、Given・When・Thenのステップキーワード、タグ・コメント・テストデータの記述方法を習得する。シナリオ作成を通じてBDDの記述スタイルを実践する。 |
| 　 | 第3章：ドメイン層の実装とテスト | 値オブジェクト・エンティティの設計原則（不変性・等価性・自己検証・ビジネスロジックのカプセル化）を学ぶ。GherkinシナリオとReqnrollを用いてテストを実装し、共通ステップ・ScenarioContext・FeatureContextを活用した再利用可能なテスト構成を習得する。 |
| 　 | 第4章：インフラストラクチャ層の実装とテスト | EF Core InMemoryを使ったDBテスト・フック（前処理・後処理）・Adapter・Repositoryパターンの実装とテストを学ぶ。参照系・更新系メソッドの演習を通じて、データアクセス層の一貫したBDDテスト手法を習得する。 |
| 2日目 | 第5章：アプリケーション層の実装とテスト | ユースケースを実現するサービス（商品検索・登録・変更）の実装と結合テストを行う。NotFoundException・ExistsExceptionの共通ステップ活用やトランザクション管理のためのフック利用など、実務的なテスト戦略を習得する。 |
| 　 | 第6章：プレゼンテーション層の実装とテスト | PlaywrightによるE2Eテスト（商品登録・検索・変更）とMoqを使ったモックテストを実践する。正常系・異常系シナリオの実装・ミドルウェアのテスト・Playwrightの応用機能（PDF生成・動画記録）まで習得する。 |

> ※ 各章末にプログラム実装演習を実施します。
