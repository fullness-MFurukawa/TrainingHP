> より正確に把握した上でキャッチコピーが生成されます。

## 確定したキャッチコピー

```
ASP.NET Coreで学ぶ、Webアプリ開発の基本と設計。
```

**選定理由：**
- シンプルで誰にでも伝わる
- 「基本と設計」でMVCの基礎から設計原則まで幅広く学べることが一言で表現できる
- 若手エンジニア・事業会社・SIerなど、どの立場からも違和感なく受け取れる
- REST API開発コースのキャッチコピー「設計原則が身につくREST API開発ハンズオン」と
  トーンが統一されており、コースシリーズとしての一貫性がある

---

## ポイント・コツ

| ポイント | 内容 |
|----------|------|
| アーキテクチャ図もアップロードする | スライドテキストだけでなく、図をアップロードするとコースの設計思想・差別化ポイントをより正確に把握できる |
| 前コースのターゲット層を引き継ぐ | 同シリーズのコースはターゲット層を統一すると、コース間のトーンが揃いやすい |
| 「それでいいです」で簡単に引き継ぎできる | 前のコースと同じ設定を引き継ぐ場合は一言で確認を済ませられる |
| シンプルな案が汎用性が高い | 幅広い層に向けたコースは、技術用語を絞ったシンプルな表現が最も刺さりやすい |
| シリーズ間でトーンを統一する | 同一シリーズのコースはキャッチコピーのトーン・文体を揃えると、受講者が「続編」として認識しやすくなる |

---

## 全体の流れまとめ

```
STEP 1｜スライド（.pptx）とアーキテクチャ図をアップロードする
STEP 2｜品質・将来性の評価を依頼する
STEP 3｜評価をMarkdown化して保存する
STEP 4｜ターゲット層を確認する（前コースと同じ場合は「それでいいです」）
STEP 5｜キャッチコピー案が自動生成される
STEP 6｜気に入った案を選択して確定する
```
