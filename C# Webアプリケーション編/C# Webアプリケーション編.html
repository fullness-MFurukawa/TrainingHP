C# Webアプリケーション編

ASP.NET Core による Webアプリケーション開発

ASP.NET Coreで学ぶ、Webアプリ開発の基本と設計。

研修概要

■ 本研修について

本研修は、C#および.NETを用いたWebアプリケーション開発を、ASP.NET CoreのMVCアーキテクチャをベースに体系的に学ぶハンズオンプログラムです。

HTTPリクエストの受け取りからController・Service・Repository・Razor Viewを経てレスポンスを返すまでの全工程を、実装しながら理解します。さらにRepositoryパターン・Adapterパターン・依存性逆転の原則（DIP）を第6章で扱い、「動くコードから設計できるコードへ」の第一歩を踏み出します。

本研修はREST API開発コースへのステップアップを見据えた設計になっており、設計原則の土台をここで確実に身につけることができます。

■ 本研修の3つの目的

本研修では、以下の3つを習得することを目的としています。

1. ASP.NET CoreによるWebアプリ開発の全体像の把握

HTTPリクエストからレスポンスまでの処理フロー・MVCの役割分担・Razor Viewによる画面生成・Data Annotationsによる入力検証を実装レベルで理解する。

2. 実務で使えるWebアプリ開発スキルの習得

リクエストパラメータの処理・PRGパターン・TempData・EF CoreによるDBアクセスなど、実際のWebアプリ開発で必要となる技術を体系的に身につける。

3. 設計原則（Repository・Adapter・DIP）の体得

Repositoryパターン・Adapterパターン・依存性逆転の原則（DIP）を実装を通じて体得し、変更に強く・テストしやすい設計の考え方を習得する。

到達目標（受講後に身につくスキル）

🌐Webアプリ開発の全体像

  • ASP.NET CoreのMVCアーキテクチャを理解し、リクエストからレスポンスまでの全工程を実装できる
  • Controller・Razor View・ViewModelの役割分担を説明・実践できる
  • Data Annotationsによる入力検証とModelStateによるエラー処理を実装できる

⚙️実務スキル

  • クエリ・ルート・フォームパラメータを適切に受け取り処理できる
  • PRGパターンとTempDataを使った安全な画面遷移を実装できる
  • EF CoreとLINQを用いたDBアクセス層を構築できる

🏗️設計原則の基礎

  • 3層アーキテクチャ（プレゼンテーション・アプリケーション・インフラストラクチャ）を設計・実装できる
  • Repositoryパターン・Adapterパターン・DIPを実装レベルで活用できる
  • 変更に強い設計の考え方を説明できる

カリキュラム詳細（全2日間）

日程 章・学習テーマ 学習内容・習得スキル
1日目 第1章：ASP.NET Coreの概要 ASP.NET Coreの特徴・MVCモデルの役割分担・技術要素（ViewModel・Data Annotations・Routing・DI・Middleware）・プロジェクト構成を把握する。
第2章：Controllerの基本機能 Controllerクラスの基本ルール・アクションメソッド・HTTPリクエストとのマッピング・戻り値ヘルパーメソッド・ModelStateによるバリデーション制御を学ぶ。
第3章：リクエストパラメータ クエリパラメータ・ルートパラメータ・フォームデータの受け取り方、Data Annotationsによる入力検証・ModelState.IsValidによるエラー処理を実践する。
第4章：Razor View Engine Razor構文・タグヘルパー・_Layout.cshtmlによる共通レイアウト・部分ビューを実装し、動的なHTML画面を生成できるようになる。
2日目 第5章：リクエスト遷移制御 PRG（Post/Redirect/Get）パターン・TempDataを使った一時データの受け渡し・二重送信防止の仕組みを実装を通じて体得する。
第6章：データベースアクセス機能の設計・実装 3層アーキテクチャの設計・Repositoryパターン・Adapterパターン・DIP（依存性逆転の原則）をEF CoreとLINQを用いて実装する。ViewModelAdapter・EntityAdapterによるデータ変換の仕組みを実装し、演習アプリで設計原則を体得する。

※ 補足-A（LINQの利用）・補足-B（SQLの利用）は自習教材として提供します。2日目は第6章の演習時間を十分に確保します。

※ 各章末にプログラム実装演習を実施します。

受講にあたっての前提知識

プログラミングの基礎知識

  • C#を用いた基本的なプログラミング（変数・条件分岐・ループ・クラス・メソッド）ができること。
  • オブジェクト指向プログラミング（クラス・インターフェイス・継承・ポリモーフィズム）の基本を理解していること。

基本的なPC・OS操作

  • Visual Studio Codeを使ったコード編集・ターミナル操作ができること。
  • WSL2（Ubuntu）環境での初歩的なコマンド入力に抵抗がないこと。

Webの基礎知識

  • HTTPリクエスト・レスポンスの基本的な概念（GETとPOSTの違い・ステータスコード）を理解していること。
  • HTML・CSSの基本的な読み書きができること。

あると望ましい知識 推奨

  • リレーショナルデータベース（テーブル・主キー・外部キー）の基本概念とSQLによるCRUD操作の経験。
  • GitHubを使ったリポジトリのクローン・コミット・プッシュなど基本的な操作の経験。
