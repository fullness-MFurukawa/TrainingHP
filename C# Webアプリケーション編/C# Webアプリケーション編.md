# 研修概要
## 本研修について
本研修は、C#および.NETを用いたWebアプリケーション開発を、ASP.NET CoreのMVCアーキテクチャをベースに体系的に学ぶハンズオンプログラムです。
HTTPリクエストの受け取りからController・Service・Repository・Razor Viewを経てレスポンスを返すまでの全工程を、実装しながら理解します。さらにRepositoryパターン・Adapterパターン・依存性逆転の原則（DIP）を第6章で扱い、「動くコードから設計できるコードへ」の第一歩を踏み出します。
本研修はREST API開発コースへのステップアップを見据えた設計になっており、設計原則の土台をここで確実に身につけることができます。
## 本研修の3つの目的
本研修では、以下の3つを習得することを目的としています。
1. ASP.NET CoreによるWebアプリ開発の全体像の把握
HTTPリクエストからレスポンスまでの処理フロー・MVCの役割分担・Razor Viewによる画面生成・Data Annotationsによる入力検証を実装レベルで理解する。
2. 実務で使えるWebアプリ開発スキルの習得
リクエストパラメータの処理・PRGパターン・TempData・EF CoreによるDBアクセスなど、実際のWebアプリ開発で必要となる技術を体系的に身につける。
3. 設計原則（Repository・Adapter・DIP）の体得
Repositoryパターン・Adapterパターン・依存性逆転の原則（DIP）を実装を通じて体得し、変更に強く・テストしやすい設計の考え方を習得する。
