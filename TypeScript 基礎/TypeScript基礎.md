# TypeScript基礎 評価レポート
# - 型安全なJavaScript開発の第一歩 -

# キャッチコピー
TypeScriptで学ぶ、型安全なWeb開発の基本と実践。
基本構文・OOP・Generics・非同期処理まで体系的に習得し、React開発・CI/CDパイプライン構築へとつながるTypeScriptの基礎を身につける研修。

# 研修概要
## ■ 本研修について
本研修は、TypeScriptによる型安全なWeb開発を、基本構文から非同期処理まで一貫して学ぶハンズオンプログラムです。
Java・C#などの他言語経験者を対象に、既存のOOP知識を活かしながらTypeScriptを効率よく習得します。Generics・Utility Types・async/awaitを体系的に学び、React研修・GitHub Actions連携へのステップアップを目指します。
## ■ 本研修の3つの目的
1. TypeScriptの型システムと基本構文の習得
変数宣言・データ型・型推論・配列・関数（オプション引数・デフォルト引数・アロー関数）・OOP（クラス・インターフェイス・継承・例外処理）・モジュール化を実装レベルで習得する。
2. TypeScript特有の高度な型機能の体得
GenericsとUtility Types（Partial・Required・Readonly・Pick・Omit等）を実装を通じて体得し、型安全な開発の真価を体感する。
3. 非同期処理とWeb開発への実践的な接続
Promise・async/await・JSON操作を習得し、API連携が当たり前の現代Web開発に直結するスキルを身につける。React研修・GitHub Actionsへのステップアップの土台を築く。
## ■ 到達目標(受講後に身につくスキル)
本研修を修了すると、以下のスキルが身につきます。
- TypeScriptの基本構文（変数・型・配列・条件分岐・繰り返し）を自走して書ける
- 関数（アロー関数・コールバック関数）とOOP（クラス・インターフェイス・継承）を実装できる
- GenericsとUtility Typesを使って型安全なコードを設計できる
- Promise・async/awaitを使った非同期処理とJSON操作を実装できる
- React開発・GitHub Actionsに必要なTypeScriptの基礎知識を習得できる

# 前提知識・スキル-> 受講にあたっての前提知識
## プログラミングの基礎知識
Java・C#などの言語を用いた基本的なプログラミング（変数・条件分岐・ループ・クラス・メソッド）ができること。
オブジェクト指向プログラミング（クラス・インターフェイス・継承）の基本を理解していること。
## 基本的なPC・OS操作
Visual Studio Codeを使ったコード編集・ターミナル操作ができること。
コマンドプロンプト・PowerShellでの基本的なコマンド入力に抵抗がないこと。
## あると望ましい知識 推奨
JavaScriptの基本的な概念（変数・関数・オブジェクト）をなんとなく知っていること（経験は不要）。
HTMLの基本的な読み書きができること。
