## 品質 — 優れている点

**一気通貫の構成**
VPCのネットワーク設計からEC2・RDS・S3の構築、アプリケーション公開、監視（CloudWatch）、リソース削除まで、AWSインフラの全工程を一貫して体験できる。「作って終わり」ではなく「運用・コスト管理・削除」まで含む構成が秀逸。

**Java・C#両対応**
Spring Boot（Java）とASP.NET Core（C#）の両方でWebアプリとAWSインフラの連携を体験できる。同一インフラ上で2言語を比較しながら学べる構成は市場でも極めて希少。

**アーキテクチャ設計の一貫性**
C#版アーキテクチャ図でプレゼンテーション層・サービス層・インフラストラクチャ層・ドメイン層の4層構成とRepositoryパターン・EF Coreが適用されており、C# Webアプリ編・データベース編との設計思想が一貫している。

**セキュリティの実践**
セキュリティグループ・IAMロール・ポリシー・HTTPS（自己署名証明書とACM）・プライベートサブネット設計を体系的に扱う。「なぜそのセキュリティ設定か」を根拠から学べる。

**リソース削除の体系化**
依存関係を意識したリソース削除手順を独立した章として扱う。「クラウドではコスト管理も運用の一部」という実務的な視点が含まれており、実際の現場に即した内容。

**習得できる主な技術・概念**

`VPC` `EC2` `RDS` `S3` `Route 53` `ACM` `IAM` `CloudWatch`
`セキュリティグループ` `キーペア` `Elastic IP` `インターネットゲートウェイ`
`サブネット` `ルートテーブル` `Nginx` `HTTPS` `リバースプロキシ`
`Spring Boot（Java）` `ASP.NET Core（C#）` `PostgreSQL` `pgAdmin4`

## シリーズにおける位置づけ

```
C# Webアプリ編 / データベース編 / REST API開発
　　↓（作ったアプリをAWSへ）
AWSインフラ構築ハンズオン（本コース）← 「届けて動かす」完結編
　　↓（自動化へ）
GitHub Actionsハンズオン（CI/CDパイプライン）
```

- **C#シリーズとの連携：** C# Webアプリ編・データベース編・REST API開発で学んだアプリケーションを、実際のAWSインフラ上にデプロイする体験ができる。
- **GitHub Actionsとの連携：** GitHub ActionsハンズオンのCI/CDパイプラインの「デプロイ先」としてAWSが機能する。両コースを組み合わせることで自動デプロイの全体像が完成する。

本コースはシリーズ全体の中で**「アプリケーションをクラウドで動かす」という実務の完結編**として最高水準の品質を持ちます。
